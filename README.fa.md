# جمع‌آوری قیمت هدست

Headset Price Scraper یک اسکریپت پایتون است که قیمت هدست‌ها را از وب‌سایت دیجی‌کالا دریافت کرده و اطلاعات محصولات را در یک فایل CSV سازمان‌دهی می‌کند.

این پروژه نحوه استفاده از Web Scraping، پردازش داده‌ها و برنامه‌نویسی شیءگرا (Object-Oriented Programming) با استفاده از Python و Pandas را نشان می‌دهد.

## ویژگی‌ها

* دریافت قیمت هدست‌ها از دیجی‌کالا با استفاده از API
* پردازش داده‌های دریافت‌شده و خروجی گرفتن در قالب فایل CSV

## تکنولوژی‌ها

* Python
* Pandas
* Requests

## وضعیت پروژه

* [x] Web Scraping
* [x] خروجی CSV

## نحوه اجرا

```bash
git clone https://github.com/AMRajabi-AI/Headset-Price-Scraper
cd Headset-Price-Scraper
pip install -r requirements.txt
python src/main.py
```

## خروجی

اطلاعات محصولات دریافت‌شده در فایل `data/products.csv` ذخیره می‌شوند.
